## A (hopefully) very gentle first introduction to Bayesian Statistics

A couple of pages introducing students of psychological science to the most basic concepts in Bayesian statistics.

The introduction has been rendered nicely in `bayesIntroduction.html`

The source code is in the quarto markdown, `bayesIntroduction.qmd`. The markdown relies on the anonymised data in `mar.csv`, and `utilities.R` holds the theme for the plots that appear throughout the markdown.

Please feel free to use it, adapt it to your needs, etc.
